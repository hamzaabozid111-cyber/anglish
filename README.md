# كابتن إنجلش (Captain English)

تطبيق أندرويد لتعلم الإنجليزي: جمل الحياة اليومية وإنجليزي الملاعب واللاعيبة.

## اللي فيه
- اسم ولقب Captain في كل تشجيع، وصوت مدرب (شاب/بنت) وصوت لاعب إنجليزي بلهجات مختلفة.
- اختبار تحديد مستوى تكيّفي من 15 سؤال.
- الأقسام: مواقف الملعب، غرفة الملابس، الحياة اليومية، الخطط، التدريب، المؤتمر الصحفي، التعليق، وضع المترجم بعداد.
- رد بالصوت أو بالاختيار، وتقييم النطق.
- قاعدة الغلطات: بعد عدد غلطات ورا بعض المدرب يترجملك الجملة بالعربي.
- مراجعة ذكية للجمل اللي غلطت فيها، وشاشة تقدم وإعدادات.
- لهجة الترجمة اختيارية: مصري أو فصحى مبسطة.

## إزاي تطلّع ملف APK (من غير ما تنزل أي برنامج)
1. اعمل حساب على github.com وأنشئ مستودع (Repository) جديد باسم `captain-english`.
2. ارفع كل ملفات المشروع في المستودع.
3. **مهم:** الملف المخفي `build-apk.yml` لازم يتحط في المسار ده بالظبط:
   `.github/workflows/build-apk.yml`
   (من صفحة المستودع: Add file ← Create new file، واكتب في خانة الاسم `.github/workflows/build-apk.yml`، والصق محتوى الملف، واضغط Commit).
4. افتح تبويب **Actions** في المستودع، واختار **Build Android APK** واضغط **Run workflow**.
5. استنى من 10 لـ 20 دقيقة. لما يخلص بالأخضر، افتح تبويب **Releases** في المستودع ونزّل `captain-english.apk` على موبايلك.
6. على الموبايل: افتح الملف واسمح بالتثبيت من مصدر غير معروف.

لو البناء فشل، افتح الخطوة اللي طلعت حمرا وابعتلي نص الخطأ.

## ملاحظات
- أصوات اللاعيبة والمدرب بتيجي من محرك الصوت في موبايلك (Google Text-to-Speech). لتحسين الأصوات: من إعدادات الموبايل ← اللغة ← محرك تحويل النص لكلام ← نزّل أصوات إنجليزي وعربي.
- التعرف على صوتك بيحتاج تسمح للتطبيق بالميكروفون، وغالباً بيشتغل مع نت.
- الـ APK بيتوقّع بمفتاح الاختبار (debug) عشان تثبّته على موبايلك. لو عايز تنزله على Google Play هنحتاج مفتاح توقيع خاص بيك.

## تشغيل تجريبي على جهازك (اختياري)
```
npm install --legacy-peer-deps
npx expo install --fix
npx expo prebuild --platform android
npx expo run:android
```
